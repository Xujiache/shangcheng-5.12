# 鸿蒙商家端：图标、主题语言与商品页

日期：2026-09-09。源码基线：`709de9c74554d337d7aee8a0674f9f1cbc1afa08`。

## 本轮改动

### 1. 全覆盖图片图标

- 使用已获确认的当前图片生成工具；不声称使用了无法核实的特定模型版本。
- 新生成 36 个通用图标及 1 个桌面启动图标，保留已有 34 个生成图标。统一石墨灰、象牙白与香槟金，不复用含义不符的图标。
- 69 个语义名称映射覆盖业务页面及组件库默认入口：返回、搜索、清除、加减、选择、弹窗、密码显示、评分、照片失败等。
- 组件库的 9 个 SVG 资源替换为对应生成 PNG；启动图标也由 SVG 换成 PNG。没有留下字体图标回退路径。
- 新增来源清单、原图及成品 SHA-256。原始生成文件保留在本机生成目录；仓库保存成品及可追溯记录。代码只处理背景、裁边与尺寸，不绘制图标形状。
- 原生系统权限弹窗、系统键盘、加载进度动画不是 App 自绘图标，保持系统实现。
- 保持 IBest UI 子模块固定提交，通过可复现适配器修改指定文件。构建时校验原始文件，发现未评审修改会失败，不能覆盖未知修改。

### 2. 主题与语言

- 三张独立外观选项卡、两条语言选项，选中边框与勾选反馈明确。每个选项直接订阅响应式状态，不再传递选中布尔快照。
- 防止慢初始化读取覆盖刚做出的选择；外观与语言分别更新。
- 保留串行、最新版本优先的保存流程；增加“保存中 / 已保存 / 保存失败重试”，不再吞掉存储异常后宣称保存成功。
- 显式主题触发的配置回调不再被当作系统主题；运行时切换语言不触发原生资源重配置。
- 本轮验证了逻辑和编译，未声称已经复现并通过全部真机选择器场景。

### 3. 商品页

- 精简标题与新增入口，统一搜索框、等宽状态 / 批量 / 管理入口。
- 状态面板采用草稿、重置、确认；点遮罩取消不改变生效条件。分类、代理商品、价格规则与批量业务均保留。
- 列表使用按需创建卡片、有限预加载、缩略图优先、原图回退、无图占位和点击重试。旧图没有缩略图时仍可显示原图。
- 图片请求绑定独立尝试编号，旧回调不会覆盖新图；缺失缩略图的短期缓存最多保留 64 条。
- 同条件刷新保留列表；请求分页成功后才推进页号；搜索防抖；换账号与页面退出丢弃旧请求。取消复选框与整行同时切换的重复触发路径。
- 后端商品列表仅新增可选 `imageThumbnailUrl` 字段，原图、金额、归属过滤和分页契约不变。该字段需要部署后端才能在线生效；本轮没有部署服务器，也没有批量回填历史图片。
