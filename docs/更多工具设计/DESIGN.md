# 量窗助手 · 更多工具

本轮交付可点击设计稿：**首页入口 → 更多工具 → 四个工具详情**。设计稿独立保存在此目录，小程序正式页面尚未接入这些入口。全部 UI 由主 Agent 设计；金额与日期的本地交互辅助模块由 GPT-6 sol 编写。

## 入口与视觉

- 首页保留原有四个工具。底部一行左侧保留格式转换，右侧增加 **更多工具 ›**，两者以短分隔线区分点击区域。新增入口不占用另一行。
- 使用现有首页的青绿色系：主色 `#0E7C66`、文字 `#15201C`、浅灰绿背景，顶部少量薄荷色光感。
- 工具白卡圆角 **18px**，主按钮 **16px**，与首页工具卡、全局按钮保持一致。控件文字使用 flex 居中。
- 图标使用同一组薄荷绿具象图形：钞票、日历、水平尺、玻璃片。保留首页原有图标素材。
- 顶部独立预留状态栏和微信胶囊区域。详情页带返回；二级页面不重复显示首页底部导航。
- 总览分为“热门工具”和“其他工具”，两组统一固定五列、多行排布。热门工具依次为三角计算、圆弧计算、优化下料、记工、格式转换；其他工具为新增四项，第五格留空。后续新增工具自然换行，末行不居中、不拉伸。窄屏保持五列，长名称分两行。

## 交互口径

### 金额

输入后即时转大写，页面无需再增加“转换”按钮，主操作为复制。支持非负金额 `0–999999999999.99`，最多两位小数，非法输入不生成结果。大写不包含“人民币”前缀，标签已说明币种，整元补“整”。复制失败保留可选择文本并给出反馈。

### 退休倒计时

首次填写三项信息：出生年月、职工类别、工种情况。按 2025 年起实施的渐进式延迟退休规则，自动计算普通职工的法定退休月份及年龄。男职工、原 50 周岁女职工、原 55 周岁女职工分别计算；女性类别以单位或社保认定为准，不能仅凭职业名称判断。

结果页优先展示法定退休年月、剩余年月日和总天数，下方保留“我的信息”和修改入口。政策结果精确到月份，日级倒计时明确以**退休月 1 日**为锚点；已到月份显示 0，实际退休状态以办理结果为准。最低缴费年限独立提示，不把退休时间等同于养老金领取资格。2025 年以前的结果不套用新政策表给出缴费年限。

类别不确定、特殊工种或特殊退休只保存信息并提示核定，不生成推测日期。此工具不计算弹性提前/延迟退休、灵活就业人员的地方适用规则或城乡居民养老保险待遇时间。

设计稿使用当前浏览器 `localStorage` 保存经过验证的出生年月、类别和工种，不保存静态倒计时。再次打开、刷新、返回页面时重新计算；跨日或重新回到前台时刷新天数。修改可以取消；保存失败保留表单且不覆盖旧记录；清除信息需要二次确认。不同设备、浏览器及不同预览域名不共享数据，清理浏览器数据后需重新填写。正式小程序接入时使用相同逻辑及 `wx` 本地存储适配。

右上角设计状态选择器仅切换演示，不覆盖用户已保存信息。示例结果标明“示例 · 未保存”。

政策依据：[全国人大常委会决定及国务院办法](https://legalinfo.moj.gov.cn/pub/sfbzhfx/zhfxfzzx/fzzxyw/202409/t20240913_506025.html)、[政府发布的完整对照表](https://www.guide.gov.cn/zwgk/fdzdgknr/flfg/gjfg/content_400014140)、[实施弹性退休制度暂行办法](https://www.mohrss.gov.cn/wap/zc/zcwj/202501/t20250101_533701.html)。核对时间：2026-09-27。

### 水平仪

设计预览使用演示读数，不访问设备传感器；界面持续显示“演示”。实际接入需处理设备方向、校准偏移、稳定读数、前后台监听释放和传感器不可用。锁定状态禁止再次校准，点击“继续测量”恢复。校准以用户确认的已知水平面为参考。

### 玻璃 K 值

结果口径明确为 **玻璃中心传热系数**，单位 `W/(m²·K)`，不等于整窗 Uw。先选择中空/真空类型，再编辑玻璃构造。厚度、气体、镀膜是常用项，边界和真空层参数逐级展开。

**2.80 和 0.70 均为结果排版示例，不是这些参数的真实求解结果。** 正式计算前需确认标准及适用结构、温度边界、材料属性、气体浓度、支撑柱材料/传热和真空模型，再固化输入字段。不得直接把本稿示例值或参数默认值当作生产计算公式。

## 查看

在仓库根目录运行：

```sh
python3 -m http.server 4176 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4176/docs/更多工具设计/index.html`。左侧可直达六个页面；右上角切换空白、错误、完成等设计状态。点击手机里的入口可以连续体验操作。仅访问本机静态文件，不连接业务后端。

金额、日期及退休政策逻辑校验：

```sh
node --test docs/更多工具设计/prototype-logic.test.mjs docs/更多工具设计/retirement-policy.test.mjs
```

## 文件

- `index.html`：预览外框与页面导航。
- `prototype.css` / `prototype.mjs`：六个页面、图形、表单、弹层和演示状态。
- `prototype-logic.mjs`：金额与日期计算，使用整数/字符串及民用日期运算。
- `prototype-logic.test.mjs`：零值、小数、金额分组、非法输入、闰日、月底和到期验证。
- `retirement-policy.mjs`：法定退休月份、缴费年限及本机存储校验，由 GPT-6 sol 实现。
- `retirement-policy.test.mjs` / `official-table-fixtures.json`：408 条官方对照表记录及政策边界、非法输入、存储失败测试。
- `previews/`：逐页截图与总览。
- `verification.json`：浏览器交互和尺寸检查记录。

本设计稿尚不代表微信开发者工具编译或真机传感器、玻璃计算验收。
