# 量窗助手潮汐表

## 数据与范围

- 从和风天气 GeoAPI 实时搜索中国潮位站；按站点 ID 查询未来 10 天的高低潮和逐小时潮位。附近 50 公里无站点时显示空结果。
- 气象预警由和风天气 Weather Alert API 提供。页面显示来源、更新时间；当前潮位和涨落速率由相邻逐小时预报线性插值得出，不是实测值。
- 潮汐页显示可复制的和风天气来源地址；预警接口的 `metadata.attributions` 原样展示。正式发布前仍需核对微信外链能力与和风天气署名条款。
- 页面提供站点收藏、定位查找、日期切换、潮位曲线、高低潮时间、倒计时、预警详情、复制与分享。
- 和风天气潮汐接口不提供浪高、官方潮型或潮汐系数。页面在“数据说明”中明确标为“当前数据源未提供”；接入这些项目需要有相应授权的数据源。

## 配置

在服务器私有环境文件中设置 `QWEATHER_API_HOST` 和 `QWEATHER_API_KEY`。前者是和风控制台分配的专属 API Host；后者只由服务器读取，不写入小程序或版本库。

后端公开接口：`/api/v1/l/tides/stations`、`/nearby`、`/forecast`、`/alerts`。接口启用限流。微信小程序的“附近站点”使用 `getLocation`，正式发布前需要在小程序管理后台完成对应隐私声明。

## 2026-09-30 页面重构

参考 [墨迹天气移动端](https://apps.apple.com/cn/app/id434209233) 的数据分层、[潮汐附近](https://apps.apple.com/cn/app/id957143504) 的曲线优先布局，以及 [气象署潮汐预报](https://www.cwa.gov.tw/V8/C/M/tide.html) 的日期和高低潮排版。没有复制品牌素材。

- 沿用首页浅绿色背景、主色与圆角 token；去掉大块渐变站点卡与重复指标卡。
- 站点、收藏和 10 天日期放在顶部；潮位、涨落状态、下一潮时、潮差、最低/最高、曲线与高低潮表集中展示。
- 站点搜索改为底部面板，保留附近查询、收藏、常用城市和无数据提示；未来日期展示当日最高潮位与首个潮时。
- 曲线按实际时间坐标连接小时数据与高低潮事件，带潮位刻度、当前时间、潮时标记及触摸读数。采用官方离屏画布导出普通图片，解决原生画布的弹层穿透和滚动错位；更新和卸载时清理临时图片。
- 顶部导航固定，数据来源、预警署名和不支持的数据项目保留。未改变其他工具、登录或业务数据。

验证：`typecheck`、针对修改文件的 ESLint、`test:more-tools`（包含新增 `verify-tide.ts`）、`test:routes`、`test:nesting` 通过。微信开发者工具使用本地完整后端与真实 QWeather 数据验证青岛/厦门，包含收藏恢复、搜索切站、北京无站点、明日预报、12:00 触摸读数、日期切换清空旧读数、说明展开、曲线滚动与站点弹层。复制内容与分享路径由页面逻辑测试验证；未向联系人发送消息。
