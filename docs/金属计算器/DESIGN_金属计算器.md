# 金属计算器 · 设计

## 页面

- 工具入口：仅在“更多工具 → 其他工具”展示金属计算器，不列入热门工具，不放小程序首页；首页不预加载金属分包。支持按金属、重量、钢材、铝材等用途搜索。
- 金属分类页：沿用小程序淡绿背景和卡片圆角；6 类截面合并成 3×2 分隔宫格，顶部直达记录和报价单。布局研究见 [UI 重构报告](UI_REBUILD_20260930.md)。
- 计算页：材料/牌号 → 尺寸/密度 → 实际吨价与参考价 → 重量和价格结果 → 报价系数/加工费。参数双列、结果双列；长数字自动整行显示。输入后延迟 200ms 重算，键盘出现时收起底部操作栏。
- 历史：显示材料、完整规格、重量、金额和保存时间；登录账号 ID 独立的本地存储，历史/常用各最多 200 条，可一键重算和删除。
- 管理端：65 行材料表，搜索、类别过滤、批量编辑吨价、重置单行、更新时间及保存。

## 数据流

`materials.ts` 是小程序材质数据源；服务器使用由它生成的 `metal-materials.json`，`verify-metal.ts` 断言两者完全一致。`specTable.ts` 只包含核实过的规格。`calculateMetal` 是无微信运行时依赖的纯函数。

服务端 `LedgerConfig(key='metal')` 保存价格、密度、价格模式与报价默认值；`normalizeMetalConfig` 对未知 ID、越界数值、数组长度与时间戳收口。`GET /l/tools/metal/config` 免登录，60 次/分钟。平台原有 `GET/PUT /p/ledger/config` 返回并更新 `metal`，只传 `metal` 时不重写 `global` 行。

## 规格来源及限制

- 等边角钢/槽钢/工字钢：[GB/T 706-2016 附录 A](https://www.synergia.cn/uploads/41683/files/GB_T706-2016-HR-Profile-Steel.pdf)。
- H 型钢：[GB/T 11263-2024 标准状态](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=8894AAFBAE28DF71A29374720910304F)，录入附录 A 基准规格。
- C 型钢：[嘉立创 FA 机械设计手册的 GB/T 6723-2017 表](https://www.jlc-jdgf.com/mcbook/GBT6723-5.htm)。该标准已废止；新标准交叉核对未完成，界面显示来源，其他档位不猜测。
- 铝型材：[米思米 20/40 系列目录](https://www.misumi.com.cn/pdf/fa/2018/p2119.pdf) 与 30 系列目录。型号如 `4040` 以特定目录型号的线重代表，其他系列/壁厚不可直接套用。

按实厚线性修正仅是重量近似，尤其 H 型钢同时有腹板与翼缘厚度；结果明确标注“按实厚修正”，不替代供货商规格书。


## P2 报价单

- 计算页只上传材料 ID、尺寸、密度、系数与整数分加工费；云端吨价始终读后台配置，手填吨价仅用于本次本地速算。保存按钮旁明确提示重新计价。
- 草稿按账号隔离；保存后后台重算，每行金额和总额均为整数分。报价系数统一取两位小数。
- 当前报价 / 已保存两个页签分别显示草稿和云端列表；每页最多 50 行，可继续加载。已保存详情独立展示，列表不重复出现在详情下方；底部合计与保存/导出常驻，正文预留滚动空间。
- `LedgerMetalQuote` 独立表便于账号范围查询、分页、删除及级联清理，避免不断膨胀用户设置 JSON。新增表配套 `deploy/ledger-metal-quote-init.sql`，重复执行安全。
- 新增 `POST quote`、`GET quotes`、`DELETE quotes/:id` 和 `POST quotes/:id/export`；导出接口再次验证有效会员和所有权，之后客户端生成文件。到期仅允许读取列表。
- 金属控制器的局部异常过滤器将 HTTP 状态统一为 200，错误码与响应壳由现有全局过滤器生成；不改变其他接口。
- CSV 包含 BOM，字符串全量引号转义，含前导空白的 `= + - @` 也加单引号；图片完整绘制全部行，超过 4000px 按比例压缩宽高，不截断末行。
- 分享复用 `shareQuoteFile`。生成与分享分成两次点击，保留微信要求的用户点击动作。生成过程有 busy 防重入。

## 资源与数值边界

- 每张报价单最多 200 行；入参和重算结果分别不超过 20KB，超过结果上限提示分单保存。
- 尺寸不超过 1,000,000mm，长度/张数不超过 100,000，张数为整数；密度 0.01–30g/cm³；系数 0.01–100；加工费不超过 9,999,999 元。
- 后端每行总重量上限 1,000,000,000kg；金额受 PostgreSQL INTEGER 限制，每张报价单总金额不超过 2,147,483,647 分。
- 本地验证数据库与原项目数据库隔离。本地后端已按用户要求停止，环境文件不入库；小程序源码使用正式服务器 API。后续验证只在服务器进行。
