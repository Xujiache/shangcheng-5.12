# 导出报表界面重构 — 2026-09-09

## 对齐与范围

按当前截图优化报表导出页，沿用薄荷绿、白底分层、已有主分段控件和顶部下拉筛选。只改原生小程序报表页，不改变金额口径、会员规则或导出数据格式。

## 设计与实现

- 范围卡增加「报表范围」说明，继续复用统计页筛选与自定义区间日历。
- 以浅薄荷底预览区显示报表类型、工人/工地范围、记工笔数和期间应计工资。
- 根据已确认范围显示记工汇总报表、个人工资单或工地对账单；长名称和大金额允许换行。
- 三个大块即时导出按钮改成单选格式行：CSV / PDF / 图片。选中使用浅绿底、细边框和圆形勾选。
- 唯一主按钮负责生成，选择格式不创建文件；生成期间禁止重复操作，未确认筛选不允许从主按钮导出。
- 空记录提示不锁定导出，因为仍可能存在补差、付款等相关账目。
- 已生成文件记录当时的范围，后续筛选变化不会篡改文件说明。
