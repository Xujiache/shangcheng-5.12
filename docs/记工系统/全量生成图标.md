# 记工模块：Image 2 全量图标替换

## 1. 对齐范围

按本轮要求替换记工模块内所有由小程序控制的图标，不只是底部导航。范围包含总览、记工明细、记一笔、人员与工地、工资结算、报表，以及它们的页头、筛选、空态、表单、导出弹窗和保存提示。

微信胶囊、状态栏、系统日期选择器和系统分享面板由微信绘制，不属于可替换的应用资产。工人姓名首字、金额符号、数据状态点、分段控件底色和用户凭证照片也不是装饰图标，保持原功能。

## 2. 图标设计与生成来源

- 使用现有三工具及记工入口的风格对照图 `assets/tool-icons-review.png` 作为材质参考。
- 30 个语义图案分别独立生成，未使用旧 SVG、字体符号拼装新图标，也没有使用一张拼图裁出多枚图标。
- 保持薄荷绿通透立体材质、浅金点缀、圆润边缘及左上光源；相同语义跨页面使用同一枚新图，不用不相关图案填补缺项。
- 原始 PNG 的 C2PA `softwareAgent` 均含 `gpt-image`、版本 `2.0`。生成工具没有直接返回模型字段，因此来源核验依据原图元数据，而不是编造模型调用参数。
- 30 款图案：总览、日历、人员、工地、钱包、报表、趋势、返回、前进、向下、向上、加号、减号、勾选、关闭、搜索、回收站、电话、编辑、保护、提示、CSV、PDF、下载、相机、时钟、模板、重置、加载、图片。

## 3. 资产处理与实现

- 按此前授权，仅通过代码处理背景、透明通道、裁切、尺寸与压缩，不改图标造型。房屋原图中的伪棋盘格已去除。
- 发布资产为 128 × 128 真透明 PNG，共 191,490 字节。当前界面最大图标为 32 px，保留高密度显示所需细节；大尺寸原图另外归档。
- 独立 `workbook-icon` 组件只接受这 30 个名称；缺图名称会报错并停止显示，不退回旧图标或复用不相关图形。
- 新增记工专用页头，保留返回和玻璃样式逻辑，不影响其他三个工具的共用页头。
- 替换 CSS 小箭头、字符加减号、原图标组件；复选框保留原生表单交互，选中图案换成生成的勾选。保存成功提示也使用生成图片。
- 加载状态旋转生成的加载图片，仅出现在实际保存、生成、分享操作中，不给取消或格式选项添加假加载状态。
- 底部图标保留原彩图，用选中文字和浅薄荷底色表达当前页，不重新染色或拉伸资产。
- 不改计薪规则、结算口径、数据、账号隔离和会员边界；本轮未修改本地工程配置、部署服务或提交代码。

## 4. 文件清单与复现

- 发布图片：`packages/ledger-mp/miniprogram/assets/workbook-icons/`
- 图片组件：`packages/ledger-mp/miniprogram/components/workbook-icon/`
- 专用页头：`packages/ledger-mp/miniprogram/components/workbook-header/`
- 原图及生成记录：`docs/记工系统/assets/generated-icons/`
- `manifest.json`：名称、提示词、来源路径及风格参考；房屋项保留的是提示词摘要，其余项目记录生成提示词。
- `processed.json`：原图与交付图 SHA-256、裁切区域、尺寸、体积、去背景像素数。
- `review-light.png` / `review-green.png`：浅色和主色底上的 64 / 26 / 18 / 14 px 对照。它们是资产审图，不是运行时页面截图。
- `verification.json`：资产覆盖及检查结果。

在仓库根目录执行：

```powershell
node scripts/prepare-workbook-icons.cjs
node scripts/verify-workbook-icons.cjs
pnpm --filter @jiujiu/ledger-mp typecheck
node scripts/verify-workbook-templates.cjs
pnpm exec tsx packages/ledger-mp/scripts/verify-workbook-flow.ts
pnpm exec tsx packages/ledger-mp/scripts/verify-workbook.ts
```

资产处理优先读取生成工具的原始文件；其他开发机无该路径时读取已归档的 `*-source.png`。不必重新调用生成工具即可复现透明 PNG。

## 5. 本轮验收结果

- 30 个原图来源和 SHA-256 检查通过，全部唯一；30 个交付 PNG 均具有真实透明通道。
- 覆盖 6 个页面、2 个公共展示组件中的 85 处图标节点，包括列表循环及条件分支的模板节点。动态导航和导出格式额外核验，全部能找到对应图案。
- 没有旧 `lz-icon` / `lz-header` 依赖，没有字符或 CSS 箭头残留，没有原生 loading 图标兜底；图片不嵌在不支持图片的 `text` 节点内。
- 小程序 TypeScript 检查通过；官方 WXML/WXSS 编译通过，覆盖 41 条页面路由、51 个模板、57 个样式文件。
- 页面逻辑回归通过：离线建档、批量记工、结算、借支、分次发薪、导出、备份恢复、请求重试与账号隔离；16 项领域/计算/存储测试通过。
- 图标总重约 187 KiB。静态主包源文件合计约 1.79 MiB，仅为源文件体积参考，不能代替微信最终打包结果。
