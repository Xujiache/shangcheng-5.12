# 图标替换后的渲染错误排查

## 收到的现象

Windows 微信开发者工具 `2.01.2510290`、基础库 `3.15.2` 报：

```text
Uncaught TypeError: Cannot read property 'length' of undefined
TypeError: SystemError (webviewScriptError)
```

目前只有这两行，没有页面、操作路径和展开后的调用栈，尚不能把异常确认归因到某一行应用代码。

## 已确认并修改的组件行为

- `workbook-icon` 的属性观察器和 `attached` 会对相同的图片/尺寸分别调用一次 `setData`。新增生命周期测试在修改前得到 2 次更新，断言失败；修改后相同状态只更新一次。
- 新组件原来在虚拟宿主内用 `wx:if` 创建图片根节点。改为常驻 `image` 根节点，缺少有效名称时仅用 `hidden` 隐藏，避免初始化时改变根节点结构。
- 保留全部 30 个生成图标及原有名称映射，未知名称仍不使用旧图或无关图标兜底。

这些是已消除的初始化/节点结构风险，不等于已经复现并确认上述基础库异常的根因。
