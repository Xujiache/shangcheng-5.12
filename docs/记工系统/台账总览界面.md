# 台账总览重构

## 设计与范围

针对总览截图，以克制的白底与薄荷绿强调色替代大面积绿底。保留原生 TS/WXML/WXSS、工资计算口径、本机免费与主动云同步边界。

## 实现

- 一张工资概览卡承载月份、期间应计、单位分列统计及四项账目；待支付用强调色，累计与期间金额明确区分。
- 原「本月已支付」改为「期间已支付」，避免查看历史月份时误读。月份结束日改为该月实际最后一天。
- 主记工按钮整宽，附批量说明；人员工地、工资结算、报表备份三个管理入口等权排列。
- 最近记录增加姓名头像、日期/工地辅助文字；空态按是否有在职人员引导建档或记工。
- 云同步错误与本机数据错误独立展示：接口不可用显示简明提示，可点击查看原始错误。未改线上服务，也不将 404 视为同步成功。
- 隐藏页面后返回的旧同步结果不更新页面；游客未开启云同步时不请求后端。

## 验证与边界

- 小程序类型检查、官方 WXML/WXSS 编译通过。
- 模拟 wx 测试通过：游客离线汇总、月份与非法输入、管理入口、空态导航、404 时保留本机金额、旧页面异步响应忽略，以及原记工到结算/导出的回归流程。
- 当前服务 `/l/workbook/access` 不可用仅有截图证据，本次未部署或验证远端修复。
- 真机/开发者工具视觉验收未完成，仍需检查长姓名、大金额、小屏和实际云服务状态。
