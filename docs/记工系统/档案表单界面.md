# 档案表单界面调整

## 需求与设计

按新增工人截图重构表单，沿用薄荷绿和圆角卡片，基本资料与计薪设置分区；同步应用于编辑档案和新增工地，不改存储模型。

## 实现

- 图标与标题组成轻量表头，名称标必填，工种/联系信息标选填。
- 四种计薪方式改为直接点选，浅绿选中态；原 picker 事件兼容保留。
- 单价改为独立金额输入行，输入无垂直 padding，避免数字下沉；显示元/天、小时、件、项。包工显示默认包工金额。
- 新档案用 0.00 占位，未填保存为零，历史单价快照不变。
- 主保存按钮与次要取消按钮分级，字段错误在表单内提示；保存中禁改、禁重复提交。
- 保留原生输入框避让键盘，金额输入增加光标与键盘间距；底部操作不悬浮覆盖字段。

## 验收

- 类型检查通过；官方 WXML/WXSS 编译通过。
- 模拟 wx 的原生页面测试覆盖四类计薪与单位、非法索引、必填和负数错误、保存状态保护、字段白名单、重开重置及原有离线保存/工资流程。
- 待开发者工具与真机验证视觉、键盘弹出、长名称、金额和小屏布局；不以静态编译代替运行截图。
