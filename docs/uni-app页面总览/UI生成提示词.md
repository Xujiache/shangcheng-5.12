# UI 生成提示词 · 经纬科技 UniApp 三端界面

> **给 UI 生成器的任务说明**
> 下面是一个多角色电商项目（门窗 / 家居建材，含定制与代理分销）的**界面清单**。三端都是 uni-app（微信小程序 / 手机 App / H5）。请依据本文档生成界面，本文档只回答三件事：
> 1. **有哪些界面**（清单与导航归属）
> 2. **界面之间的关系**（从哪进、跳到哪、谁是主流程）
> 3. **每个界面有哪些功能**（界面要承载的能力与状态）
>
> 本文档**不包含任何具体设计**：配色、字体、间距、栅格、图标、组件库、动效风格均不在范围内，由你自行决定或后续按设计规范套用。文中出现的「Tab」「弹层」只是导航与层级说明，不代表视觉样式。
>
> 名词约定：**Tab 界面** = 底部导航一级界面；**二级界面** = 从 Tab 或其它界面跳入的独立页面；**弹层/浮层** = 不占独立路由的界面内交互层，需在其所属界面中体现；**独立入口界面** = 不出现在任何 Tab 中、只能从外部或启动流程进入。

## 0. 三端共有、所有界面都要具备的通用能力

- **三态**：加载中 / 空数据（要说明空因） / 加载失败（可重试）。
- **登录态**：未登录时受限功能要引导登录，登录后停留在原意图上继续；三端登录互相独立（用户端、商家端、平台端各一套身份）。
- **列表**：分页或「加载更多」，到底要有明确结束提示；筛选与搜索条件变化要重置到第一页。
- **表单**：必填与格式校验、提交中禁用、提交结果反馈、失败不丢已填内容（草稿）。
- **危险操作**：删除 / 下架 / 驳回 / 退出 / 支付前一律二次确认；需要理由的操作必须填写理由。
- **角色与可见性**：同一界面在不同角色（用户 / 厂家 / 门店 / 会员 / 平台管理员）下可见功能不同；价格类信息有「按身份分级显示」与「隐藏为询价（此时不可下单）」两种状态。
- **实时性**：客服会话、新订单提醒等需要实时刷新能力。
- **金额与状态**：所有金额、订单状态、审核结果以服务端为准，界面不做本地假成功。

# 一、用户端（微信小程序，27 个界面）

**端定位**：面向普通消费者与分销客户的商城。可逛、可买、可售后，也可申请成为商家、做推广分佣、预约上门量尺。

**Tab**：首页 / 分类 / 购物车 / 我的。

## 1.2 界面关系

```
【登录】(独立，所有受限功能的前置)
   └─ 登录成功 / 跳过 → 首页

【首页】(Tab)
   ├─ 搜索 → 【搜索】→【搜索结果】→【商品详情】
   ├─ 广告位 → 站内界面（无有效目标时提示）
   ├─ 4 个快捷入口（新品/热销/活动/会员）→【频道】
   ├─ 推荐商品卡 →【商品详情】
   └─ 底部 Tab ⇄ 分类 / 购物车 / 我的

【分类】(Tab)
   ├─ 搜索 →【搜索】
   ├─ 查看全部 / 二级分类 →【商品列表】→【商品详情】
   └─ 商品卡 →【商品详情】

【商品详情】(核心转化)
   ├─ 加入购物车 → 购物车
   ├─ 立即购买 →【确认订单】
   └─ 客服 →【在线客服】

【购物车】(Tab)
   ├─ 去结算 →【确认订单】
   │     ├─ 选择地址 →【收货地址】→【编辑地址】
   │     └─ 提交订单 →【支付】
   │            ├─ 支付成功 →【我的订单】(待发货)
   │            └─ 支付超时 → 我的
   └─ 查看全部收藏 →【我的收藏】→【商品详情】

【我的】(Tab)
   ├─ 订单宫格 / 全部订单 →【我的订单】→【订单详情】
   │        ├─ 待付款：去支付 →【支付】 / 取消订单
   │        ├─ 待发货：催发货
   │        ├─ 待收货：确认收货
   │        ├─ 已完成：申请售后（弹层选原因）
   │        └─ 再来一单 → 购物车
   ├─ 个人信息 →【个人信息】（含账号绑定、账号安全弹层）
   ├─ 收藏 →【我的收藏】
   ├─ 领券中心 →【领券中心】；我的优惠券 →【我的优惠券】
   ├─ 收货地址 →【收货地址】→【编辑地址】
   ├─ 预约量尺 →【预约量尺】
   ├─ 推广分佣 →【推广分佣】
   ├─ 附近门店 ⇄【附近门店】/【门店地址】→【商品列表】
   └─ 商家入驻 →【商家入驻】

【订单分享公开页】← 外部分享链接直接打开，页内不再跳转
```

**主流程一句话**：逛（首页/分类/搜索）→ 商品详情 → 购物车或立即购买 → 确认订单 → 支付 → 我的订单 → 订单详情 → 售后。

## 1.3 各界面功能

### 1) 首页
- 顶部搜索入口，点击进搜索界面。
- 广告位轮播：可左右切换；有站内目标才跳转，无有效目标给出提示。
- 四个快捷入口：新品、热销、活动、会员。
- 推荐商品瀑布流：支持触底加载更多、到底提示。
- 商品卡上可**直接收藏**（未登录先登录）与**快捷加购**（自动取该商品可用规格；无可用规格时给出提示）。
- 未登录且商家限制访客可见价格时，卡片价格位显示为「登录可见」。

### 2) 分类
- 一级分类横向切换；二级分类横向切换，含一个「全部」。
- 面包屑显示当前「一级 / 二级」，并显示该分类商品总数。
- 商品双列流；点卡片进商品详情。
- 「查看全部」带当前分类进商品列表。
- 支持在列表内直接收藏。

### 3) 购物车
- 商品行：勾选、商品信息、规格、单价、数量增减（失败回滚并提示）。
- 单选 / 全选；底部合计实时变化。
- 编辑模式：可多选删除，删除需二次确认。
- 「去结算」：未勾选商品时提示；**勾选了不同商家的商品时禁止合并下单并提示**（后端不支持合并订单）。
- 收藏横滚区：未登录显示引导卡；可取消收藏、可一键加购。
- 空态：购物车为空时仍保留收藏区并可回首页。
- 底部 Tab 切换。

### 4) 我的
- 头部：头像、昵称；未登录显示登录按钮，已登录可退出登录（二次确认）。
- 订单区：待付款 / 待发货 / 待收货 / 售后四个入口，以及「全部订单」。
- 工具区：我的收藏、领券中心、我的优惠券、收货地址、预约量尺、推广分佣、附近门店、门店地图、分享小程序、商家入驻。
- 未登录点击订单与需登录的工具先跳登录。
- 分享小程序（小程序内为原生分享入口）。
- 已登录时本界面是资料同步与实时消息的挂载点（后台刷新个人资料）。

### 5) 商品详情
- 商品图片轮播，带当前序号 / 总数。
- 价格区：按访客身份分级展示价格（零售 / 批发 / 会员价），或显示「询价 + 锁价原因」；显示价格类型标签与身份标识。
- 基本信息：名称、已售、评价数、标签。
- 规格与配送、服务说明区。
- 用户评价区；无评价显示空态（不造假数据）。
- 商品详情图文与参数表；缺失时给空态提示。
- 底部操作栏：收藏、客服、加入购物车、立即购买。
- 规格弹层：选规格组合（或按尺寸输入长宽并实时算面积与合计）、数量增减、配送方式、确认按钮；**规格未选满时给明确提示，不自动替用户选**。
- 收藏可切换；未登录时收藏/加购/购买/客服均先登录。
- 商家未开放购买时（价格隐藏为询价），购买按钮不可用并提示。
- 分享本商品（小程序原生分享）。
- 失败态：商品不存在或已下架，可返回。

### 6) 商品列表
- 顶部标题随来源变化（分类 / 商家 / 关键词）。
- 排序切换：最新、销量、价格升、价格降；切换后回到第一页。
- 显示结果总数；商品双列流；支持下拉刷新与触底加载更多。
- 空态「暂无商品」。
- 列表内可收藏，可快捷加购。

### 7) 登录
- 两种方式：微信一键登录（主）、手机号 + 短信验证码登录（辅）。
- 手机号与验证码格式校验；获取验证码有 60 秒倒计时防重发。
- 必须勾选用户协议 / 隐私政策才能登录，协议以弹层展示正文。
- 「跳过」以游客身份继续浏览（受限功能仍会再引导登录）。
- 登录成功回到首页；若从分享链接进入，登录后自动完成邀请关系绑定。

### 8) 确认订单
- 收货地址卡：无地址时引导新增；点开进地址选择界面，选择结果回填本页。
- 商品清单：来自购物车勾选或「立即购买」的单个规格。
- 配送方式选择（厂家直发 / 本地配送 / 门店自提）。
- 优惠券选择弹层：仅列出本单商家券与平台券；未达门槛的券标注还差多少金额；可选择不使用。
- 备注输入。
- 价格明细：商品金额、配送费、优惠券抵扣。
- 底部合计与「提交订单」；缺少地址或商品时给出提示并阻止提交。
- 提交成功后进入支付界面。

### 9) 支付
- 展示订单金额、订单号、剩余支付时间倒计时。
- 支付方式选择（微信支付）。
- 「立即支付」调起微信支付；成功进订单列表（待发货），用户取消与支付失败分别提示。
- 倒计时归零提示订单已关闭并引导离开。
- 支付协议弹层。
- 缺订单参数时提示并返回。

### 10) 我的订单
- 状态 Tab：全部 / 待付款 / 待发货 / 待收货 / 售后。
- 订单卡：订单号（可复制）、状态、最多两行商品、合计、件数、操作按钮组。
- 按状态提供操作：待付款（取消订单、去支付）、待发货（查看详情、催发货）、待收货（查看物流、确认收货）、已完成（申请售后、再来一单）。
- 取消订单与确认收货需二次确认。
- 「再来一单」把仍在售的商品加入购物车；全部失败时明确提示不加入。
- 空态「暂无订单」。
- 从其它界面返回本界面时自动刷新。

### 11) 订单详情
- 状态条：当前状态说明；待付款显示关闭倒计时。
- 收货地址快照、商品清单（含规格与件数）、价格明细（商品总额 / 配送费 / 优惠 / 实付）。
- 订单信息：订单号（可复制）、下单/付款/发货/完成时间、物流单号（可复制）、买家备注。
- 状态操作：待付款（取消、去支付）、待发货（催发货）、待收货（申请售后、确认收货）、已完成（申请售后）。
- 申请售后弹层：选择原因（退货退款 / 换货 / 维修 / 不想要了）并提交。
- 售后提交失败时可转在线客服。
- 加载失败可重试。

### 12) 收货地址
- 两种模式：管理模式与「下单选择」模式（标题与点击行为不同）。
- 地址卡：收货人、电话、默认标记、地区与详址；可设为默认、编辑、删除（删除二次确认）。
- 底部新增地址入口。
- 选择模式下点卡片即回填并返回上一界面。
- 空态引导新增。

### 13) 编辑地址
- 表单：收货人、手机号、所在地区、详细地址、地图选点。
- 地区选择：预设城市快捷选择 + 手动输入。
- 地图选址：小程序端调用地图选点，其它端用关键字搜索地点结果挑选。
- 「设为默认地址」开关。
- 保存校验：收货人姓名、手机号、地区、详址；保存成功返回上一界面。

### 14) 个人信息
- 资料编辑：头像（拍照/相册上传）、昵称、性别（选择弹层）、邮箱。
- 账号绑定区：手机号、微信，分别显示已绑定/未绑定并提供绑定动作；已绑定时说明如何更换。
- 账号安全区：修改登录密码、更换/绑定手机号（短信验证码，含倒计时）。
- 保存按钮在有改动且校验通过时才可用；无改动直接返回。
- 保存后多端资料保持一致（其它设备自动更新）。

### 15) 搜索
- 输入框自动聚焦，可一键清空。
- 历史搜索：本地保存最多 10 条、去重后置顶，可单条删除、可清空（二次确认）。
- 热门搜索：展示热门词（接口无数据时用内置兜底词）。
- 回车或点词进入搜索结果。

### 16) 搜索结果
- 顶部可继续编辑关键词并重新搜索。
- 两个 Tab：商品、店铺。
- 商品：双列结果流，触底加载更多，空态提示。
- 店铺：店铺卡展示名称、类型（厂家/门店）、地区、经营品类；点击**以店铺名作为关键词重新搜索商品**。
- 切 Tab 或换词都重置到第一页。

### 17) 附近门店
- 进入时请求定位；未授权时顶部提示条可再次请求，并说明「授权后可看到准确距离」。
- 门店卡：排名、名称、距离（未授权显示「距离未知」）、地址、营业状态标识、电话、导航。
- 电话直接拨号；导航调起地图。
- 点门店或「看商品」进入该商家的商品列表。
- 空态「附近暂无门店」；与门店地图界面互相切换。

### 18) 门店地址
- 地图视图：展示所有门店点位；点位与列表选择联动。

## 2.3 各界面功能

### 1) 登录
- 两种方式：账号 + 密码、手机号 + 短信验证码。
- 账号/密码与手机号/验证码格式校验；获取验证码 60 秒倒计时。
- 必须同意用户协议才能登录，协议以弹层展示。
- 未入驻账号：提示并引导去商家入驻（取消则退出登录）。
- 刚提交过入驻申请时，顶部显示「入驻申请已提交」提示条，可关闭；此时默认切到短信登录并回填手机号。
- 入口提示「还未成为商家？立即申请入驻」。

### 2) 商家入驻
- 步骤指示器：验证手机号 → 填写资料 → 等待审核。
- 第一步：手机号 + 短信验证码验证（60 秒倒计时），可返回登录。
- 主体信息：主体类型（门店/厂家）、店铺名（或工厂名）、营业执照法定名称、统一社会信用代码、法定代表人。
- 联系方式：联系人、联系电话、所在地区、详细地址。
- 经营信息：主营品类多选（家具 / 窗帘布艺 / 灯具 / 装饰）。
- 提交按钮仅在全部必填且至少选 1 个品类时可用；提交即视为同意入驻协议。
- 提交成功后展示完成态（审核约 1 个工作日、最长不超过 24 小时）并可返回登录。

### 3) 设置密码
- 展示脱敏手机号，说明首次登录需设置 6 位以上密码。
- 两个输入框：新密码、确认密码，均可切换明文显示。
- 校验：两次都 ≥6 位且一致；不符时给出具体提示。
- 主按钮「设置密码并进入商家工作台」；次按钮「暂不设置 · 退出登录」。

### 4) 首页（工作台）
- 顶部店铺信息：店铺名、头像、会员状态标识。
- 今日数据三项：今日订单、新客户、销售额（含环比升降指示），点击可跳对应模块。
- 快捷入口九宫格（按平台功能开关动态显隐）：商品、订单、客户、客服、营销、门店、员工、代理商品、价格规则等。
- 选品广场卡片：横滑展示推荐商品，可进选品广场。
- 本周销售：本周累计、日均、峰值与柱状趋势。
- 待办事项：订单待发货、退款待处理、门店授权申请、员工待入职，各带数量，点击进对应界面。
- 加载失败可重试。

### 5) 商品
- 搜索框（商品名 / 编号）。
- 状态 Tab：全部 / 在售 / 已下架 / 审核中 / 已驳回（带数量）。
- 操作行：分类管理、代理商品、价格规则、批量操作。
- 商品卡：图片、名称、规格、零售价、库存、状态、标签、销量；编辑与「更多」。
- 「更多」动作：上架/下架、复制链接、分享商品、查看数据、删除（删除二次确认）。
- 批量模式：多选商品后批量上架、下架、删除。
- 新增商品按钮；分页加载更多；空态「暂无商品」。

### 6) 订单
- 搜索（订单号 / 收货人）；状态 Tab：全部 / 待付款 / 待发货 / 已发货 / 已完成 / 售后（带数量）。
- 订单卡：订单号、状态、客户与地区、件数、时间、金额、操作按钮。
- 发货弹层：选择快递公司 + 填写运单号（格式校验），确认发货。
- 查看物流：显示快递公司与单号；无信息时提示。
- 新订单实时到达提醒（可配置震动 + 声音 + 提示，或静默）。
- 下拉刷新；加载更多；空态。

### 7) 数据
- 周期切换：今日 / 本周 / 本月 / 本年；另有日期选择器可直接查看某一天。
- 概览卡：总销售额、订单数、客单价、TOP 商品销量（含环比方向）。
- 销售趋势折线图。
- 热销商品 TOP10 榜（可跳商品列表）。
- 商品分析柱状图（分类销量）。
- 客户分析环形图（新客占比）+ 图例。
- 各类图表都有空态（数据不足时不画假图）。

### 8) 我的
- 头部：头像、店铺名、商户号、评分、会员标识。
- 会员卡：显示当前套餐摘要，点击进会员开通。
- 分组列表：账户（个人信息、分享 APP）、经营（佣金设置）、应用（系统设置、检查更新）、支持（联系我们）。
- 联系我们：显示客服电话与邮箱，可拨号。
- 退出登录（二次确认）。
- 底部显示当前 App 版本号。

### 9) 添加/编辑商品（最重的表单界面）
- 商品主图：多图上传，可设主图、替换、上移/下移、预览、删除，有数量上限。
- 基本信息：商品标题、商品分类（弹层选择）、商品简介。
- 商品详情图：多图上传（数量上限高于主图）。
- 定价模式二选一：
  - 标准定价；
  - 按尺寸定价：每平米单价、起售费、尺寸单位、最小/最大尺寸，并实时价格预览。
- 物流方式：厂家直发 / 本地配送 / 门店自提。
- 商品规格：最多 4 组规格，每组可增删规格值；规格变化后自动重新生成 SKU 组合。
- SKU 价格与库存：支持批量填价（按倍数）与批量填库存；每个 SKU 可单独设库存、批发价、零售价、会员价，并可上传 SKU 图；底部汇总总库存与价格区间。
- 价格显示规则入口（全局规则）。
- 两个提交动作：存草稿、提交审核。
- 校验：名称、分类、至少 1 张主图必填；图片必须上传完成；按尺寸模式必须填每平米单价；标准模式 SKU 不能为空。

### 10) 分类管理
- 两个 Tab：厂家自定义分类 / 平台分类（平台分类只读，显示说明且隐藏所有操作）。
- 分类树：根分类可展开/收起子分类，显示子项数量与「自定义」标识。
- 操作：上移、下移（同级排序）、编辑（名称，长度限制）、删除（二次确认，提示该分类下商品会变为未分类）。
- 新增：新增顶级分类、在某分类下新增子分类。
- 编辑浮层：分类名称、上级分类选择。

### 11) 代理商品
- 从代理申请成功跳入时显示成功提示条。
- 统计：代理商品数、待审核、已通过、合作厂家。
- Tab：全部 / 待审核 / 已通过 / 已驳回 / 已下架。
- 卡片：出厂价、我的零售价、加价幅度、申请时间、价格自动同步标识、状态与按状态变化的操作。
- 操作：待审核（取消申请、调整加价）、已通过（下架、调整加价、编辑商品）、已下架（删除、重新上架）、已驳回（删除、查看厂家）。
- 加价弹层：按百分比加价或按固定金额加价，实时预览最终售价。
- 下架与取消申请需二次确认；空态引导去选品广场。

### 12) 订单详情
- 状态条：待付款 / 待发货 / 已发货 / 已完成 / 已取消 / 售后中 / 已退款，待付款显示剩余支付时间。
- 收货地址区：姓名、电话、地区详址；一键复制；「一键识别」把粘贴的地址文本解析成结构化字段（解析结果可套用）。
- 商品信息：商品明细与件数。
- 费用明细：商品总额、优惠、运费（为 0 显示包邮）、实付金额。
- 订单信息：订单编号、下单/付款/发货时间、配送方式、买家备注。
- 底部操作：发货（填运单号）、查看物流、打印订单（占位）、联系客户（拨号）。
- 分享：生成订单分享链接，可勾选对外可见字段、有效期与简介，也可撤销分享。

### 13) 售后处理

- 加载更多；空态「暂无售后单」。

### 14) 客户管理
- 搜索（昵称 / 手机号）。
- Tab：全部（带总数）/ 分佣客户 / 会员 / 普通客户。
- 客户卡：头像、昵称、客户类型标签、脱敏手机号（可拨号）、订单数、累计消费、最近下单时间。

### 15) 佣金设置

### 16) 门店管理

- 门店卡：等级标识、名称、区域、状态、联系人电话、地址、授权有效期。
- 操作：通过（二次确认，按等级授予有效期）、驳回、联系（拨号）、授权设置、查看记录。
- 空态「暂无门店」。

### 17) 门店授权

- 授权有效期：开始时间只读、结束时间可选择；底部提示到期后影响。

### 18) 员工管理

- 空态「暂无员工」。

### 19) 店铺装修

## 3.2 界面关系

```
【登录】(独立) → 登录成功 → 首页

【首页｜驾驶舱】(Tab)
 ├─ 顶部铃铛 →【消息中心】
 ├─ 待办：待审核商户 →【商户入驻审核】

 │        待审核提现 →【提现审核】

 └─ 底部 Tab ⇄ 商户 / 订单 / 数据 / 我的
```

## 3.3 各界面功能

### 1) 登录
- 管理员账号 + 密码登录；说明「仅授权人员可访问」。
- 输入校验：账号至少 3 位、密码至少 6 位才可提交；密码可切换明文。
- 勾选并查看管理员守则 / 隐私政策 / 信息收集清单（弹层展示正文）。
- 忘记密码入口；登录中禁用按钮。
- 非平台角色的账号登录时提示无权限。

### 2) 首页（驾驶舱）
- 问候语与当前管理员昵称。
- 今日新订单与今日 GMV 两个大数，含升降幅。
- 消息铃铛（带待办总数角标）。
- 平台概览四卡：商户总数、累计订单、累计 GMV、用户总数，各带变化量。
- 近 7 日注册趋势小折线（数据不足时不显示）。
- 待办事项列表：待审核商户、待审核商品、广告创意待审、售后投诉、待审核提现；有数量时高亮，为 0 时显示「已清空」。
- 快捷入口：商户、商品、广告、会员。
- 加载失败可重试。

### 3) 商户
- 顶部统计：商户总数、厂家数、门店数、已停用数。
- 搜索（商户名称 / 联系人），本地过滤。
- Tab：全部 / 厂家 / 门店 / 已停用。
- 全局功能开关条：厂家与门店按钮图标显示开关。
- 商户卡：首字母头像、名称、类型标签、停用标识、套餐与累计 GMV、信用/等级/低驳回率徽章。
- 操作：查看详情（弹层）、停用 / 恢复（二次确认）。

# 四、三端关系总览（给 UI 生成器的全局视角）

```
用户端（买家）                      商家端（厂家 / 门店）                 平台端（运营）
─────────────────────          ─────────────────────────           ────────────────────────
逛 → 下单 → 支付 → 售后   ⇄     接单 → 发货 → 处理售后         ⇄    审核商户/商品/售后/提现
申请成为商家 ───────────────→    入驻审核通过后开始经营               审核入驻申请
推广分佣（拉新）                 会员/套餐、营销、代理、门店、员工      维护套餐、功能开关、权限、协议
预约量尺                         选品广场选货（代理厂家商品）          维护选品广场推送
```

**跨端必须对齐的三处业务闭环**（生成 UI 时不要漏掉任何一端）：

1. **订单闭环**：用户端下单 → 商家端接单发货 → 用户端确认收货/申请售后 → 商家端处理售后 →（争议时）平台端售后审核。
2. **入驻闭环**：用户端「商家入驻」→ 平台端「商户入驻审核」→ 通过后商家端可登录经营（未设密码先设置密码）。
3. **分佣/资金闭环**：用户端「推广分佣」产生佣金 → 商家端「佣金设置」定比例 → 平台端「提现审核」放款。
