# 鸿蒙商家端 · 双页操作与信息密度调整

## 范围与设计

仅迭代商品编辑、订单详情及其局部组件，不改接口、订单金额口径、数据库、签名和业务权限。保留生成图片图标与现有中英文、深浅色主题。

### 商品编辑

- 主图改为单条横向缩略图带，第一张标识封面，添加入口同行；移除重复封面大图和独立添加横条。仍支持预览、管理、排序、替换及失败重试，保持 10 / 20 张限制。
- 分类改为紧凑整行「字段—当前值」，点击整行进入确认式选择；商品描述默认摘要，展开后编辑，折叠不丢内容。
- 两种计价方式并排；尺寸上下限、零售价格与库存等相关数字成对呈现，配送方式仍为整行多选，避免英文挤成窄标签。
- 只有一个 SKU 时点击价格库存直接进入编辑，确认一次即应用到商品草稿；多 SKU 仍保留规格矩阵和父面板确认。规格管理独立保留。
- 数字填写优先于可选规格图片；取消不回写、空白数字不默认为零；尺寸计价摘要不把 SKU 零售价误标成尺寸成交价。
- 主卡片留白 18 → 14 vp、卡片间距 14 → 10 vp；保留正文 14–15 fp，按钮/数字输入 44–50 vp 触控高度，不以压缩字号换密度。

### 订单详情

- 首屏紧凑展示状态、应付/订单/付款金额语义及可复制订单号；不再重复强调同一总金额。
- 配送方式、姓名电话、地址、客户备注和物流整合为一张卡片；备注直接可见，联系和复制操作保留。
- 商品清单与费用明细合并，所有商品、运费、优惠仍可核对；创建/付款/发货时间放入可展开记录，减少默认重复信息。
- 发货确认面板再次展示收货信息和客户备注，先核对再填写物流；仅待发货且刷新成功的订单可发货。
- 分享选择项更紧凑，敏感客户资料明确标注；继续保留分享预填防过期覆盖、重复提交保护和地址解析不改订单的边界。

## 真机简测（待验证）

1. 新建单规格商品 → 编辑价格库存 → 取消应保持原值；再次编辑应用后主界面摘要立即更新，但未点底部保存不提交服务端。
2. 多规格商品 → 修改一项 SKU → 取消父面板应保持原数据；尺寸上下限与英文键盘场景检查可见字段和底部按钮。
3. 订单详情核对状态、金额、收货、备注、物流与商品；展开/收起时间记录不丢页面数据，分享取消不修改订单。
4. 有主图与无图、长名称/地址、大金额、中英文、深浅色与大字体各快速目视一遍。不用真实订单执行发货。
