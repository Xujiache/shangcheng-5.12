The direct original CLI thus has the same visible problem; the backend job being `succeeded` is not a quality pass. `pdftotext -layout` and 72 DPI page PNGs are retained under `/root/deployment-verification/linux-windows-parity/legacy-slide-diagnostic-20260929/` on the isolated server. No platform output patch was accepted. The verifier now checks page count, all expected text, rendered line layout, backend/direct raster equality, and major pixel changes; it does not require an embedded image for vector-only slides.
