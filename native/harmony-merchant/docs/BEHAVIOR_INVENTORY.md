# 商家端业务行为基线

这份清单是原商家端的行为规格，不是旧前端源码的移植说明。鸿蒙工程只根据接口契约、字段含义和可观察业务结果重新实现；任何 `.vue`、前端组件、状态管理或跨端运行时代码都不得进入本仓库。

状态含义：

- `COMPILED`：对应 ArkTS/ArkUI 实现已进入当前未签名 HAP，并通过严格类型编译。
- `DEVICE`：必须在已配置 AGC 的 HarmonyOS NEXT 真机上确认，当前统一保持待验收。
- “等价”指入口、输入、操作结果、错误语义与权限一致；支付、升级、地图、分享和通知使用鸿蒙官方能力，不照搬 Android 的旁加载方式。

## 跨页面不变量

1. 所有认证请求共享一次 refresh；refresh token 轮换后同时更新内存与 Asset Store。若 Asset Store 瞬时写入失败，当前进程继续使用服务器刚签发的新令牌并移除旧落盘副本，避免冷启动误用已撤销令牌。
2. 网络故障、超时和非鉴权服务错误不得清除登录态；只有明确过期、吊销、停用或主动退出才清理。主动退出必须先在 Asset Store 写入受保护的注销标记，再撤销远端会话；即使凭据删除失败，杀进程后也不得恢复旧会话。新的成功登录在令牌全部落盘后才移除该标记。
3. 文件上传、地图、相机、拨号、分享、相册保存、Push、IAP 和 AppGallery 更新只能调用鸿蒙官方 Kit，不嵌入旧页面或 WebView。
4. 冷启动读取 Asset Store 时，只有官方 `NOT_FOUND` 表示无本地会话；服务不可用、访问拒绝、数据损坏或数据库错误必须保留凭据并提供重试，不能把用户误导到登录页覆盖原会话。
5. 页面参数、列表筛选意图、权限、上传字段、订单金额和交易状态保持服务端契约；客户端不伪造成功、进度、支付单或物流动作。
6. 当前清单的 `DEVICE` 项必须在手机、折叠屏和平板上完成后，才能把整体状态从“已编译”升级为“功能验收完成”。
7. WebSocket 的连接、消息、关闭和错误回调只允许修改其所属连接的状态；旧连接的迟到回调不得断开已建立的新连接。
8. 前台展开/折叠、旋转和分屏会实时更新窗口尺寸：紧凑窗口使用五项悬浮底栏，宽窗口切换导航栏；隐藏主页面不因实时事件执行网络刷新，返回时再按最新数据重载。
